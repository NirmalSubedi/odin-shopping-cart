# Shop Cart

A mock store site to implement shopping cart.

[Shop Now!](#)

## Skills Demonstrated

- Building Single Page Application **(SPA)**.

- Applying changes to the single page with the help of React Router to manage routes.

- Testing react components with the help of **RTL** (React Testing Library).

- Writing tests that focus more on application behavior rather than implementation of code.

- Modularizing css rulesets to component level scope with **CSS Modules**.

- Setting **'favicon'** of site to set the image of the tab next to site name.

- Testing components that render with react router components.

- Using **jest-dom** matchers to easily test the state of the user interface.

- Simulate user interactions with the user interface by using the **userEvent** api from React Testing Library.

- Mocking component dependencies to unit test.
